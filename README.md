# 📷 Capacitor Barcode Scanner

An Ionic Angular app that scans barcodes and QR codes using the Capacitor plugin. Lightweight and mobile-optimized.

## ✨ Features

- 📱 Barcode scanning via Capacitor
- 🔄 Real-time scan result display
- 🧪 Mobile testing with Capacitor Live Reload

## 🛠️ Tech Stack

- Ionic Framework
- Angular
- Capacitor Plugins (Barcode Scanner)

## 🚀 Run Locally

```bash
npm install
ionic build
npx cap open android
